\section{Dataset}

\field{Source:}{Kaggle, ``LCA Programs (H-1B, H-1B1, E-3) Visa Petitions'' (CC BY-NC-SA 4.0),
taken from the US Department of Labor (DOL); six yearly CSV files, FY2017--2022, downloaded on
21 October 2026. Each row is one Labor Condition Application (LCA). Before hiring a foreign worker
on an H-1B, H-1B1 or E-3 visa, an employer must file one, stating the job, where the person will
work and the \emph{prevailing wage}: the minimum pay DOL sets for that job, area and experience
level. DOL then approves (certifies) or denies it.}

\field{Why it is raw:}{the decision labels are spelled differently before and after FY2020;
FY2019's wage column holds the \emph{offered} wage, not the prevailing wage; FY2019's work location
is blank in 88\% of rows; wages come in five pay units with typing errors (an ``hourly'' wage of
46{,}301, a yearly wage of \$1\,billion); 1{,}769 spellings of about 1{,}100 occupations;
255{,}125 spellings of employer names; 24\% of rows are exact copies of another row.}

\section{Data preparation}
Every rule was worked out on the exploration set and saved; the test set was later cleaned with
the same saved rules, never re-worked. No rows are dropped: every row still has a valid decision,
so a bad wage is set to missing (and marked) instead.

\field{Split, before looking at the data:}{80\% for exploration, 20\% held back for testing, seed
42. Ideas for tests come from looking at the data, and testing an idea on the data that gave it is
circular, so all EDA and cleaning rules use only the 80\%. All filings of one employer go to the
same side, because they are near-copies and would otherwise appear in both; each side keeps the
same mix of years and decisions (stratified group k-fold).}

\section{Basic questions and problem statement}

\minihead{Basic questions}
\begin{enumerate}[label=\arabic*.]
  \item Which employers file the most? (Infosys, TCS, Google, Amazon, EY; the top 10 file 16\%.)
  \item Which jobs? (Mostly software: computer jobs are 65\% of filings, and one title alone is 30\%.)
  \item How many filings are approved? (91\%; only 0.87\% are denied.)
  \item Have wages risen? (Median prevailing wage $+33\%$ from FY2017 to FY2022.)
  \item Do some regions pay more? (West \$105k vs Midwest \$78k.)
\end{enumerate}

\begin{figure*}[!t]
  \figfile{\figdir fig05_visa.png}{4.6cm}
  \caption{E-3 filings sit $+8.8\%$ above the median for the same job, state and year, H-1B
  $+1.6\%$, and the gap holds at every employer size.}
  \label{fig:visa}
\end{figure*}

\begin{figure*}[!t]
  \figfile{\figdir fig07_employer_volume.png}{4.6cm}
  \caption{Denials are highest at employers with 2--10 filings a year, yet E-3 is denied more in every size group.}
  \label{fig:volume}
\end{figure*}

\begin{figure}[!ht]
  \figfile{\figdir fig09_seniority.png}{3.9cm}
  \caption{``Senior'' titles sit $+10\%$ above others in the same job and ``junior'' $-16\%$, so
  the relative wage shows the pay level an employer chose.}
  \label{fig:senior}
\end{figure}

\minihead{Our problem statements}
\noindent\fbox{\begin{minipage}{\dimexpr\linewidth-2\fboxsep-2\fboxrule\relax}
\textbf{P1 (primary).} For the same occupation, state and year, do E-3 (Australian) filings have a
different prevailing wage from H-1B filings, and does the difference remain within the same
employer?

\smallskip
\textbf{P2.} Are E-3 filings denied more or less often than H-1B filings from employers of the
same size in the same year, and within the same employer?
\end{minipage}}

\field{Why they are new:}{the basic questions look at one column at a time. DOL sets the
prevailing wage from the job, area and experience level; the visa is not part of it, so ``no
difference'' is the natural starting point for P1. A difference would mean employers file the two
groups at different pay levels, which the data shows only indirectly (Fig.~\ref{fig:senior}). P1
holds fixed what the basic questions show moves wages most (job, place, year), and then the
employer. P2 asks whether the raw denial gap (E-3 denied 5.8$\times$ as often in the exploration
set, 6.9$\times$ in the test set) survives employer size, the main other factor EDA found
(Fig.~\ref{fig:volume}). It is not a Simpson's paradox: E-3 is denied more in every size group
too, so the question is how much of the gap size explains.}

\field{Correlation, not causation:}{both statements compare \emph{filings}; they don't claim the
visa causes anything. Australians may simply be hired into more senior roles, and worker
experience and education aren't in the data. To claim cause we would need worker-level data to
compare similar workers, or a rule change that affects only one visa, studied before and after.
We have neither, so we make no causal claim.}

\section{Statistical inferences}

\field{Rows tested:}{the 20\% held back: 794{,}670 filings from 33{,}314 employers never seen
during exploration, cleaned with the saved rules; E-3 vs H-1B only (H-1B1 is 0.4\%, a separate
program). Wage tests use FY2017--18 and FY2020--22 (FY2019 has no prevailing wage) and rows with a
valid wage and work state.}

\field{Common design, fixed before the test data was opened:}{each test is $\beta$ in
$y_i=\beta\,\mathrm{E3}_i+\alpha_{c(i)}+\varepsilon_i$, where $\alpha_c$ is a separate level
(\emph{fixed effect}) for each comparison cell, e.g.\ one occupation in one state in one year.
Each choice has one reason:}
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=1pt]
  \item \textbf{One level per cell}: $\beta$ is the E-3 minus H-1B gap \emph{inside} cells, so job,
  place and year can't create it.
  \item \textbf{Standard errors grouped by employer}: one employer's filings are near-copies
  (Section~2), not independent, and ignoring that makes the SE too small. Employers are the
  independent units, so the $t$-test uses employers $-\,1$ degrees of freedom.
  \item \textbf{Holm correction}: four tests at 5\% each give up to a 19\% chance of a false
  alarm; Holm keeps it at 5\% overall.
  \item \textbf{Smallest meaningful difference (MID)}: with this many rows even a tiny gap is
  significant, so the 95\% CI decides: \emph{meaningful} (CI beyond the MID), \emph{possibly too
  small} (CI includes it) or \emph{negligible} (CI inside it).
\end{itemize}
Power, checked before the run (the chance of finding a gap the size of the MID): T1 1.00,
T2 0.999, T3 0.16, T4 0.93.

%------------------------------------------------------------ Test 1
\clearpage
\subsection*{Test 1 (P1): do E-3 filings have a different prevailing wage for the same job,
state and year?}

\tpart{a}{Hypotheses, written before running the test}
{\small
\begin{tabularx}{\linewidth}{@{}K{3.4cm} Y@{}}
\toprule
$H_0$ & $\beta=0$ \\
$H_1$ & $\beta\neq0$ \\
Significance level & $\alpha=0.05$ overall (Holm, 4 tests) \\
Side & two-sided \\
Test & $t$-test on $\beta$, one level per occupation $\times$ state $\times$ year, SE grouped by employer \\
Smallest difference that matters & 5\% ($|\beta|\ge\log1.05=0.049$) \\
\bottomrule
\end{tabularx}}

$y$ = log yearly prevailing wage, so $\beta$ is the E-3 minus H-1B gap in log points
($\approx$\%). Two-sided, because P1 and P2 ask whether the groups differ in either direction.
5\%, because it is about \$4{,}400 at the median wage, about one year of pay growth here, and half
the gap between ``senior'' and other titles in the same job: a smaller gap wouldn't put a worker at
a different pay level.

\tpart{b}{Other tests we considered}
Two groups and a symmetric number outcome suggest a two-sample $t$-test, but the groups must be
compared within the same job, state and year (Fig.~\ref{fig:visa}), and filings
aren't independent. A regression with one level per cell makes all 2{,}729 within-cell
comparisons at once, and grouping the SE by employer handles the near-copies.
{\footnotesize
\begin{tabularx}{\linewidth}{@{}L{2.4cm} Y@{}}
\toprule
\textbf{Also considered} & \textbf{Why we did not use it} \\
\midrule
Welch $t$-test & compares the relative wage of the two groups, but treats filings as independent, so its SE (0.0027) is 2.4$\times$ too small. Run as a check: $t=20.7$, same decision \\
Mann--Whitney U test & compares ranks, which can't be matched to a 5\% MID; log wage is already symmetric, so ranks add nothing; also treats filings as independent \\
Two-group comparison & comparing all E-3 with all H-1B filings mixes differences in job, state and year into the gap \\
\bottomrule
\end{tabularx}}

\tpart{c}{Result}
{\small
\begin{tabularx}{\linewidth}{@{}K{3.4cm} Y@{}}
\toprule
Rows used & 408{,}671 (10{,}433 E-3), 19{,}299 employers \\
Estimate & $+9.1\%$ ($\hat\beta=0.087$; raw gap $+9.6\%$) \\
95\% confidence interval & $+7.7\%$ to $+10.5\%$ \\
Test statistic (d.f.) & $t=13.66$ (19{,}298) \\
p-value (raw, Holm-adjusted) & $3.0\times10^{-42}$ ($8.9\times10^{-42}$) \\
Decision & reject $H_0$ \\
Verdict & meaningful: the whole CI is above 5\% \\
\bottomrule
\end{tabularx}}

For the same job, state and year, E-3 filings have a prevailing wage about 9\% higher than H-1B
filings, well past the 5\% that matters. Job, state and year explain almost none of the raw
$+9.6\%$ gap. The result is steady across years ($+8$ to $+12\%$, not planned in advance; Fig.~\ref{fig:est}).

\begin{figure*}[!t]
  \figfile{\figdir fig13_inference_estimates.png}{4.3cm}
  \caption{All four results with 95\% CIs; the grey band is $\pm$MID. Tests 1--3 clear it; Test 4's CI overlaps it.}
  \label{fig:est}
\end{figure*}

%------------------------------------------------------------ Test 2
\needspace{18\baselineskip}
\subsection*{Test 2 (P1): does the wage gap remain within the same employer?}

\tpart{a}{Hypotheses, written before running the test}
{\small
\begin{tabularx}{\linewidth}{@{}K{3.4cm} Y@{}}
\toprule
$H_0$ & $\beta=0$ \\
$H_1$ & $\beta\neq0$ \\
Significance level & $\alpha=0.05$ overall (Holm) \\
Side & two-sided \\
Test & as Test 1, cells = employer $\times$ occupation $\times$ state $\times$ year \\
Smallest difference that matters & 5\% \\
\bottomrule
\end{tabularx}}

Only employers that file both visas for the same job, state and year count. If the Test~1 gap
disappeared here, it would only mean that higher-paying employers hire Australians; if it remains,
the same employer files the two groups differently.

\tpart{b}{Other tests we considered}
Holding the employer fixed removes its pay policy, industry and lawyer, which Test~1 leaves open;
one level per cell does this without assuming anything about how employers differ.
{\footnotesize
\begin{tabularx}{\linewidth}{@{}L{2.4cm} Y@{}}
\toprule
\textbf{Also considered} & \textbf{Why we did not use it} \\
\midrule
Paired $t$-test & on cell averages it treats a cell with 1 E-3 and 500 H-1B filings like a balanced one. Run as a check with one gap per employer (695, independent): $+5.3\%$, $t=6.59$, $p=9\times10^{-11}$ \\
Wilcoxon signed-rank test & the rank version of the paired $t$-test; it tests the median employer gap, not an average in \%, so it would repeat the paired $t$-test \\
Matching & pairing each E-3 filing with an H-1B filing throws away most H-1B filings without removing more bias \\
\bottomrule
\end{tabularx}}

\tpart{c}{Result}
{\small
\begin{tabularx}{\linewidth}{@{}K{3.4cm} Y@{}}
\toprule
Rows used & 71{,}060 (3{,}356 E-3), 695 employers, 1{,}906 cells \\
Estimate & $+6.8\%$ ($\hat\beta=0.065$) \\
95\% confidence interval & $+5.3\%$ to $+8.3\%$ \\
Test statistic (d.f.) & $t=9.24$ (694) \\
p-value (raw, Holm-adjusted) & $2.9\times10^{-19}$ ($5.8\times10^{-19}$) \\
Decision & reject $H_0$ \\
Verdict & meaningful: the whole CI is above 5\% \\
\bottomrule
\end{tabularx}}

The same employer files its E-3 workers at a prevailing wage about 7\% higher than its H-1B
workers in the same job, state and year. That is about 75\% of the Test~1 gap, so the gap comes
mostly from \emph{how} employers file, not \emph{which} employers hire Australians (Test~2 covers
only employers filing both visas, so the two numbers come from different sets of employers).

%------------------------------------------------------------ Test 3
\needspace{18\baselineskip}
\subsection*{Test 3 (P2): are E-3 filings denied more often by employers of the same size?}

\tpart{a}{Hypotheses, written before running the test}
{\small
\begin{tabularx}{\linewidth}{@{}K{3.4cm} Y@{}}
\toprule
$H_0$ & $\beta=0$ \\
$H_1$ & $\beta\neq0$ \\
Significance level & $\alpha=0.05$ overall (Holm) \\
Side & two-sided \\
Test & regression on denied (1/0), one level per employer-size group $\times$ year, SE grouped by employer \\

all six years are used. 0.5\,pp, because the H-1B denial rate is 0.78\% (exploration set), so it

\tpart{b}{Other tests we considered}
Employer size affects denials the most (Fig.~\ref{fig:volume}), so the comparison is within size
group and year. A regression on a 1/0 outcome (a \emph{linear probability model}) gives the gap
directly in percentage points, the unit of the MID, with no extra assumption about its shape.

Among employers of the same size in the same year, E-3 filings are denied 3.8\,pp more often.
Employer size explains only 17\% of the raw gap: it shrinks the gap but doesn't reverse it, so

to see through the noise, but the real gap is about eight times that, so it was found easily.
\emph{Not planned in advance:} the gap shrinks from $+6.6$\,pp in FY2018 to $+1.6$\,pp in FY2022.

\section{Limitations}
\begin{itemize}
  \item \textbf{Association, not cause} (Section~4): we show that filings differ, not that the
  visa causes it.
  \item \textbf{Prevailing wage, not pay received.} It is the legal minimum, and the
  experience-level column was removed from this version of the data; the relative wage shows it
  only indirectly (Fig.~\ref{fig:senior}). State is coarser than the metro area DOL actually uses.
  \item \textbf{FY2019 left out of the wage tests}, since its file has no prevailing wage, and
  most of its work locations are blank.
  \item \textbf{Copies kept.} If some identical rows are export errors, big employers count too
  much; grouping the SE by employer keeps the uncertainty honest, but we didn't re-run the tests
  without the copies.
  \item \textbf{Tests 2 and 4 cover only employers filing both visas}, which are larger than average.
  \item \textbf{Denial here is DOL's check of the form}, not the visa decision, which USCIS makes later.
  \item \textbf{Extras not planned in advance.} The year-by-year results and the employer-level
  checks of Tests 2 and 4 were not in the plan and are not Holm-corrected. The full test plan, and
  what changed in it, is in \code{report/preregistration.md}.
\end{itemize}
